Алгоритм
Три шага — одна соль

CO₂ + NaOH → ____
Что образуется?
Шаг 1
Найди кислоту за кислотным оксидом. Определи кислотный остаток и его валентность.
CO₂ → H₂CO₃ → остаток CO₃, валентность II
Шаг 2
Определи металл из основания и его валентность.
NaOH → металл Na, валентность I
Шаг 3
Составь формулу соли по правилу валентностей. Вода образуется всегда.
Na(I) + CO₃(II) → Na₂CO₃  |  + H₂O
Итог
CO₂ + 2NaOH → Na₂CO₃ + H₂O

Запомни
Кислотный оксид реагирует только с растворимым основанием. С нерастворимыми основаниями реакции нет.
Кислотный оксид + растворимое основание → Соль + Вода
CO₂ + 2NaOH → Na₂CO₃ + H₂O
  • Щёлочь → растворимое основание (NaOH, KOH, Ca(OH)₂…)
  • Нерастворимое основание → реакции нет
  • Вода → образуется всегда
