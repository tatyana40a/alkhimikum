Анализирую
С чем реагирует основный оксид?
Алгоритм
Три шага — одна соль
На примере CuO + H₂SO₄
CuO + H₂SO₄ → ____
Что образуется?
Шаг 1
Определи металл из оксида и его валентность.
CuO → металл Cu, валентность II
Шаг 2
Определи кислотный остаток из кислоты и его валентность.
H₂SO₄ → остаток SO₄, валентность II
Шаг 3
Составь формулу соли по правилу валентностей. Вода образуется всегда.
Cu(II) + SO₄(II) → CuSO₄  |  + H₂O
Итог
CuO + H₂SO₄ → CuSO₄ + H₂O

Запомни
Основный оксид реагирует с кислотой — образуются соль и вода. С основаниями он не реагирует.
Основный оксид + Кислота → Соль + Вода
CuO + H₂SO₄ → CuSO₄ + H₂O
  • Металл из оксида → входит в состав соли
  • Кислотный остаток → входит в состав соли
  • Вода → образуется всегда
  • С основанием → реакции нет
