Ключевой закон
Металл вытесняет из раствора только тот металл, который стоит правее него в ряду активности.
  • ✅Fe левее Cu → Fe вытесняет Cu из раствора
  • 🚫Cu правее Fe → Cu не вытесняет Fe

Запомни
Реакция металла с раствором соли — реакция вытеснения. Более активный металл вытесняет менее активный из раствора его соли.
Металл + Соль → Новая соль + Новый металл↓
Fe + CuSO₄ → FeSO₄ + Cu↓
  • Условие → вытесняющий металл стоит левее (активнее) в ряду активности
  • Нет реакции → если металл правее металла в соли
  • Признаки → изменение цвета раствора, налёт нового металла на пластинке
