Как пользоваться
Найди ион металла из новой соли (верхняя строка) и ион кислотного остатка (левый столбец). На пересечении — растворимость:

Пример
HCl + AgNO₃ → HNO₃ + AgCl

Когда образуется газ?
Нестойкие кислоты сразу разлагаются
💨 Угольная кислота
H₂CO₃ → H₂O + CO₂↑
Бесцветный газ без запаха.
💨 Сернистая кислота
H₂SO₃ → H₂O + SO₂↑
Бесцветный газ с резким запахом.
💨 Сероводородная кислота
H₂S↑ (сама летучая)
Газ с запахом тухлых яиц.
Пример
H₂SO₄ + Na₂CO₃ → Na₂SO₄ + H₂O + CO₂↑
H₂CO₃ нестойкая → H₂O + CO₂↑
Алгоритм
Как предсказать результат
Три шага для любой реакции
Шаг 1
Запиши возможные продукты — новая кислота и новая соль.
HCl + AgNO₃ → HNO₃ + AgCl
Шаг 2
Проверь соль по таблице растворимости: ион металла + ион остатка → Н?
Ag⁺ + Cl⁻ → Н → осадок AgCl↓
Шаг 3
Проверь кислоту: это H₂CO₃, H₂SO₃ или H₂S? Тогда выделится газ.
H₂CO₃ → CO₂↑ + H₂O
Вывод
Есть осадок или газ → реакция идёт.
Нет ни того, ни другого → реакция не идёт.

Запомни
Реакция кислоты с солью — реакция обмена. Она идёт только если образуется осадок, газ или вода.
Кислота + Соль → Новая кислота + Новая соль
  • Осадок → ион металла + ион остатка дают Н в таблице растворимости
  • Газ → образуется нестойкая кислота: H₂CO₃→CO₂↑, H₂SO₃→SO₂↑, H₂S↑
  • Нет реакции → все продукты растворимы и устойчивы
