Все химические реакции делятся на четыре типа.

💥
Разложение
AB → A + B
из одного — несколько
🔄

A + BC → AC + B
А вытесняет В из соединения
↔️
Обмен
AB + CD → AD + CB
обмен частями
Подсказка
Соединение — один продукт.
Разложение — один реагент.
Замещение — простое вещество + сложное → новые.
Обмен — два сложных вещества меняются частями.

Алгоритм
Расстановка коэффициентов
Четыре шага
Шаг 1
Запиши уравнение без коэффициентов. Посчитай количество атомов каждого элемента в левой и правой частях.
H₂ + O₂ → H₂O  |  H: 2=2 ✓  |  O: 2≠1 ✗
Шаг 2
Расставляй коэффициенты в такой очерёдности: металлы → неметаллы → водород → кислород. Подбери коэффициент чтобы уравнять каждый элемент.
O: слева 2, справа 1 → ставим 2 перед H₂O
Шаг 3
После изменения коэффициента пересчитай все остальные элементы и при необходимости добавь коэффициенты.
H₂ + O₂ → 2H₂O  |  H: слева 2, справа 4 → ставим 2 перед H₂
Шаг 4
Проверь: количество атомов каждого элемента одинаково с обеих сторон. Знак равенства означает равенство атомов.
2H₂ + O₂ → 2H₂O  |  H: 4=4 ✓  |  O: 2=2 ✓
Важно
Коэффициент стоит перед формулой и умножает все атомы в ней. Изменять формулы нельзя — только ставить коэффициенты.
Задание 2
Расставь коэффициенты
Перед каждым веществом — даже если коэффициент 1
Al + Cl₂ → AlCl₃
Fe + HCl → FeCl₂ + H₂
H₂O₂ → H₂O + O₂
NaOH + AlCl₃ → Al(OH)₃ + NaCl
KClO₃ → KCl + O₂
Al₂O₃ + HNO₃ → Al(NO₃)₃ + H₂O
Итоговый вывод
📖
Четыре типа реакций
  • Соединение A + B → AB → один продукт
  • Разложение AB → A + B → один реагент
  • Замещение A + BC → AC + B → простое + сложное
  • Обмен AB + CD → AD + CB → два сложных
Очерёдность уравнивания:
металлы → неметаллы → водород → кислород
число атомов каждого элемента слева = справа
